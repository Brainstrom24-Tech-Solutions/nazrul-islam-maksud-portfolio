# Nazrul Islam Maksud — Executive Portfolio

Premium luxury black/gold executive portfolio built with Next.js Pages Router, Tailwind CSS, GSAP/ScrollTrigger and Lenis.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Stack
- Next.js 14
- React 18
- Tailwind CSS
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- React Icons

## Assets
The supplied executive portrait is included at `public/nazrul-maksud.jpg`.
